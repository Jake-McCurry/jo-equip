name: Editorial link placement
description: Scope editorial linking requests to the intended occurrence, not every repetition.
---
When applying an editorial linking sheet, do not assume a repeated sentence should be linked everywhere. Preserve the requested location and unrelated wording.

**Why:** The user corrected the Pastors FAQ implementation: links on “JO EQUIP” and “Become a Growing Church” in its repeated closing sentence belong only in the first FAQ answer, not every answer.

**How to apply:** Check repeated occurrences before applying text-based link rules; verify both the intended linked occurrence and the later plain-text occurrences.
