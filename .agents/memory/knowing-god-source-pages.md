---
name: Knowing God source pages
description: Presentation rule for converting Knowing God PDF front matter and similar source material into JO EQUIP pages.
---

Convert source-derived Knowing God material into exact, selectable, semantic HTML with responsive layouts. Do not use full-page PDF renders or screenshots as the production page content.

**Why:** The expected experience is a modern mobile-first webpage while preserving the source wording and meaningful emphasis exactly; a screenshot-based page is neither responsive nor appropriately readable.

**How to apply:** Use the PDF as the source of truth and visual verification reference. Extract structured text, remove only running page furniture and line-wrap artifacts, preserve meaningful typography such as hymn underlining, and audit the result against rendered source pages.
