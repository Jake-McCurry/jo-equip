"# SEO Task 017: Resolve Duplicate Content Between BB Walking Spirit & Ministry Holy Spirit

## Background

During the SEO audit, duplicate or substantially similar content was identified under the following two URL paths:

### BB Walking Spirit

/categories/growth/bb-walking-spirit/

### Ministry Holy Spirit

/categories/growth/ministry-holy-spirit/


The review has confirmed that **BB Walking Spirit should be retained as the preferred SEO version**.

The objective is to consolidate duplicate URLs where the same resource exists under both folders, while ensuring that unique Ministry Holy Spirit content is not unnecessarily removed.

---

# Example of the Duplicate URL Issue

The following URLs represent the same page/topic:

### Preferred URL — BB Walking Spirit


https://equip.jesusonline.com/categories/growth/bb-walking-spirit/empowered-for-supernatural-living


### Duplicate URL — Ministry Holy Spirit


https://equip.jesusonline.com/categories/growth/ministry-holy-spirit/empowered-for-supernatural-living


For pages with this type of clear one-to-one relationship, implement a **301 permanent redirect** from:


/categories/growth/ministry-holy-spirit/empowered-for-supernatural-living


to:


/categories/growth/bb-walking-spirit/empowered-for-supernatural-living


---

# Objective

Implement the following SEO approach for all affected URLs:

1. Retain **BB Walking Spirit** as the preferred and indexable SEO version.
2. Identify URLs where the same page/resource exists under both:

   * `/categories/growth/bb-walking-spirit/`
   * `/categories/growth/ministry-holy-spirit/`
3. Implement a **301 permanent redirect** from the duplicate Ministry Holy Spirit URL to the corresponding BB Walking Spirit URL.
4. Where a Ministry Holy Spirit page has no direct BB Walking Spirit equivalent and must remain available, retain the page and review its indexation status separately.
5. Remove redirected and non-indexable URLs from XML sitemaps.
6. Update internal links to point directly to the preferred BB Walking Spirit URLs where an equivalent exists.

---

# Required Implementation

## 1. Retain BB Walking Spirit as the Preferred SEO Version

All approved URLs under:


/categories/growth/bb-walking-spirit/


should remain the preferred SEO versions.

For these URLs:

* Keep the existing URL unchanged.
* Keep the existing content unchanged unless separately instructed.
* Allow search engines to crawl and index the page.
* Do not add a `noindex` directive.
* Use a self-referencing canonical URL.
* Keep the URL in the XML sitemap if it is intended to be indexed.
* Ensure the URL is not blocked by `robots.txt`.

### Example

For:


https://equip.jesusonline.com/categories/growth/bb-walking-spirit/empowered-for-supernatural-living


the canonical should reference itself:


<link rel=""canonical"" href=""https://equip.jesusonline.com/categories/growth/bb-walking-spirit/empowered-for-supernatural-living"">


---

## 2. Implement 301 Redirects for Duplicate Ministry Holy Spirit URLs

Where a Ministry Holy Spirit URL has a clear one-to-one equivalent under BB Walking Spirit, implement a **server-side 301 permanent redirect**.

### Example

#### Source URL


https://equip.jesusonline.com/categories/growth/ministry-holy-spirit/empowered-for-supernatural-living


#### 301 Redirect

↓

#### Destination URL


https://equip.jesusonline.com/categories/growth/bb-walking-spirit/empowered-for-supernatural-living


The final implementation should ensure that:


Ministry Holy Spirit URL
        ↓
       301
        ↓
BB Walking Spirit URL
        ↓
       200


### Important

Apply a 301 redirect only when:

* The page under Ministry Holy Spirit and BB Walking Spirit represents the same resource.
* The page content is duplicate or substantially identical.
* There is a clear one-to-one equivalent.
* BB Walking Spirit is the approved preferred version.

Do not redirect Ministry Holy Spirit URLs to unrelated BB Walking Spirit pages.

---

# 3. Ministry Holy Spirit URLs Without a Direct Equivalent

Before implementing redirects, review the affected Ministry Holy Spirit URLs.

If a Ministry Holy Spirit URL does **not** have a corresponding BB Walking Spirit URL, do not automatically redirect it.

For such URLs, determine whether:

### Scenario A: The Page Is Unique and Should Continue Ranking

If the content is unique and provides distinct value:

* Keep the page indexable.
* Use a self-referencing canonical.
* Keep it in the XML sitemap if appropriate.

### Scenario B: The Page Must Remain Available but Should Not Be Indexed

If the page must remain accessible to users but should not compete in search results:


<meta name=""robots"" content=""noindex, follow"">


For these pages:

* Keep the page accessible to users.
* Do not block the page in `robots.txt`.
* Remove the URL from XML sitemaps.
* Use an appropriate canonical strategy based on the actual page relationship.

### Important

Do not apply `noindex` automatically to every Ministry Holy Spirit URL.

The appropriate treatment should depend on whether the page:

* Is a duplicate.
* Has a direct equivalent.
* Is unique.
* Needs to remain indexable.

---

# 4. Do Not Use 301 and `noindex` Together

For a duplicate Ministry Holy Spirit URL that is being permanently redirected:


301 → Corresponding BB Walking Spirit URL


Do not also implement:


<meta name=""robots"" content=""noindex, follow"">


on the redirected URL.

The 301 redirect is the primary consolidation mechanism.

Use one appropriate strategy per URL.

---

# 5. Canonicalization

## BB Walking Spirit URLs

All preferred and indexable BB Walking Spirit URLs should use a self-referencing canonical.

Example:


<link rel=""canonical"" href=""https://equip.jesusonline.com/categories/growth/bb-walking-spirit/page-slug"">


## Ministry Holy Spirit URLs That Are 301 Redirected

Do not rely on canonical tags as a replacement for the 301 redirect.

The URL should permanently redirect directly to the corresponding BB Walking Spirit URL.

## Ministry Holy Spirit URLs That Remain Live

If a Ministry Holy Spirit URL remains accessible:

* Use a self-referencing canonical if it is a unique and indexable page.
* Consider canonicalization to the BB Walking Spirit equivalent only where there is a valid page relationship.
* Do not force canonicalization to an unrelated page.

---

# 6. XML Sitemap

The XML sitemap should contain only URLs intended to be indexed.

## BB Walking Spirit

Keep indexable BB Walking Spirit URLs in the XML sitemap.

## Ministry Holy Spirit

Remove from XML sitemaps:

* URLs that return a 301 redirect.
* URLs with a `noindex` directive.

Do not include redirected or `noindex` URLs in the XML sitemap.

---

# 7. Internal Linking

Where internal links currently point to a Ministry Holy Spirit URL that has a corresponding BB Walking Spirit equivalent:

Update the internal link to point directly to the BB Walking Spirit URL.

### Example

Instead of linking to:


https://equip.jesusonline.com/categories/growth/ministry-holy-spirit/empowered-for-supernatural-living


link directly to:


https://equip.jesusonline.com/categories/growth/bb-walking-spirit/empowered-for-supernatural-living


This helps ensure that:

* Users are directed to the preferred URL.
* Search engines consistently discover the preferred version.
* Internal links do not unnecessarily pass through redirects.

Do not change internal links where there is no appropriate BB Walking Spirit equivalent.

---

# 8. Preserve Content

The purpose of this task is to consolidate duplicate URLs, not unnecessarily remove content.

Where a Ministry Holy Spirit page has an equivalent BB Walking Spirit page:

* Retain the content on the BB Walking Spirit page.
* 301 redirect the Ministry Holy Spirit URL to the corresponding BB Walking Spirit URL.

Where a Ministry Holy Spirit page is unique:

* Do not delete the page solely because it belongs to the Ministry Holy Spirit folder.
* Review the appropriate indexation treatment based on its content and purpose.

---

# 9. robots.txt

Do not block the following folder solely for the purpose of resolving duplicate content:


/categories/growth/ministry-holy-spirit/


Do not implement:


Disallow: /categories/growth/ministry-holy-spirit/


The URLs should remain accessible to search engines where necessary for proper processing of redirects or `noindex` directives.

# 10. URL-Level Decision Framework

Apply the following logic to every affected Ministry Holy Spirit URL.

| URL Situation                                                                  | Required Action                                                          |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| Exact or substantially duplicate BB Walking Spirit equivalent exists           | **301 redirect to corresponding BB Walking Spirit URL**                  |
